# LeafScan AI 🌿

A mobile app that detects tomato leaf diseases using deep learning.

## Tech Stack

- React Native with Expo
- FastAPI
- TensorFlow / Keras
- MobileNetV2

## Planned Features

- Capture a photo or select an image from the gallery.
- Predict the tomato leaf disease.
- Display the predicted class and model score.
- Process images without a database or permanent backend storage.

## Project Structure

- `backend/` — Prediction API and trained model
- `mobile/` — React Native app (planned)
- `training/` — Model training notebook
- `results/` — Evaluation reports and graphs
- `data/` — Dataset split information

## Dataset

[PlantVillage on Kaggle](https://www.kaggle.com/datasets/emmarex/plantdisease)

## Status

Model training and evaluation are complete. Backend and mobile app development are in progress.

> Portfolio project. Predictions may be incorrect and do not replace expert advice.
